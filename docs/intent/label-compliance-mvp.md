# Confirmed Statement of Intent: Label Compliance MVP

- **Outcome:** A full-stack Agentic Label Compliance MVP (**FastAPI** backend + **Angular 19 & Angular Material** frontend + single **PostgreSQL 16 `JSONB`** database) that ingests product label PDFs (exported from graphic design software), 16-section GHS MSDSs, official government letters (公文), and notarized source-change certificates, retrieves live Taiwan MOA `EIR027` registry data on-call, and produces a field-by-field **Label Update Checklist** with interactive `[doc_id, page, box_2d]` visual highlights on the source documents.
- **User:** Regulatory Affairs (RA) specialists managing a single company's Taiwan agrochemical/chemical catalog (~10–500 registered products) across mixed English and Traditional Chinese documents.
- **Why now:** Replace manual cross-checking across English source-change certificates/MSDSs, Traditional Chinese product label artwork PDFs, government letters, and the MOA registry so indirect downstream changes (entity/contacts, GHS hazard/precaution drift, MOA registry sync status, open official mandates) are never missed.
- **Success:** Uploading a change certificate or MSDS for a registered product (`許可證字號`) and running a compliance audit executes a **Two-Phase Copilot loop** (Phase 1: 4 deterministic/SQL function-calling tools including on-call MOA `EIR027` lookup → Phase 2: Constrained Decoding into `ComplianceAuditReport` JSON) where clicking any citation chip or checklist row in the Angular Material UI jumps the document viewer to `page` (served via `/api/documents/{doc_id}/pages/{page}/image`) and renders a razor-sharp `[ymin, xmin, ymax, xmax]` (`0–1000`) highlight box via an inline `<svg viewBox="0 0 1000 1000" preserveAspectRatio="none">` overlay.
- **Constraint:**
  1. **Unified Constrained Parsing & Ephemeral Upload Handling:** Uploaded PDFs (MSDSs, LoA/COR certificates, 公文) are rendered purely in memory via `PyMuPDF` (`fitz.open(stream=pdf_bytes, filetype="pdf")`), and uploaded JPEG/image labels (including APHIA drawn modification instructions) are normalized in memory via `Pillow` (`ImageOps.exif_transpose`), without writing raw uploads to disk; pages are saved as `<= 1600px` WebP in `{STORAGE_DIR}/pages/{doc_id}/` and passed in interleaved batches with global 1-based page markers (`["=== PAGE {global_page_no} ===", img, ...]`, max 8 pages or 5-page windows with nullable per-window fields) to `Gemini 2.5 Flash / Flash-Lite` (Paid-tier `GEMINI_API_KEY` in git-ignored `.env`, or GCP Vertex AI toggle) using Pydantic `response_schema` (`GroundedField[T]` ordered `verbatim_text` → `value` → `page` → `box_2d` with `0–1000` coordinate bounds validation).
  2. **Single-Store DB & On-Call MOA `EIR027` Retrieval:** Single PostgreSQL 16 database configured via discrete `POSTGRES_*` variables (`SQLAlchemy URL.create()`). Instead of bulk-downloading all permits on a weekly schedule, the backend retrieves only the target product's MOA `EIR027` record (`PesticideData.aspx?$filter=...` + its 4 JSON sub-endpoints) **on-call** when queried/audited and caches that product's snapshot in PostgreSQL via `ON CONFLICT (reg_no) DO UPDATE`.
- **Out of scope (for MVP):** Bulk weekly background cron jobs (`APScheduler`), camera/EXIF photo handling, Qdrant Cloud, vector embeddings (`pgvector` deferred until a large fuzzy 公文 archive requires it), `IBM Docling` / `Mistral OCR` / `DocLayout-YOLO` / `RapidOCR`, and `Crawl4AI` / `Playwright` headless browser scraping.
- **Future Enhancements (Post-MVP):**
  - **APHIA Official Announcement & Chemical Assessment Lookup:** Automated querying/syncing of official pesticide announcements (`農藥公告`), banned/restricted/carcinogen lists (`禁/限用農藥` / `可能致癌農藥狀態` on `pesticide.aphia.gov.tw`), and ACRI chemical/toxicology risk assessments (`acri.gov.tw`), which are not included in the `EIR027` OpenData JSON API.
